# Resumen de la sesion

## Objetivo
Preparar el equipo del estudiante con todo el software necesario para el curso
Sistemas Operativos, y dejar listas las maquinas virtuales usadas en el taller
de la Unidad de Aprendizaje #3 (Instalacion y configuracion de Sistemas
Operativos UNIX sobre maquinas virtuales).

## Programas instalados

- **Git** (ya estaba instalado) - control de versiones
- **Visual Studio Code** (ya estaba instalado) - editor/IDE
- **Windows Terminal** (ya estaba instalado) - terminal moderna
- **Oracle VirtualBox 7.2.14** - hipervisor para maquinas virtuales
- **VirtualBox Extension Pack 7.2.14** - descargado de download.virtualbox.org,
  instalado via VBoxManage aceptando la licencia PUEL (hash SHA256 del archivo
  ExtPack-license.txt calculado localmente para el accept-license)
- **MSYS2** - entorno GCC/Make para compilar en Windows
- **WSL2 + Ubuntu** - subsistema Linux para Windows

## Maquinas virtuales para el taller (Linux, FreeBSD, Solaris)

Instrucciones tomadas de la diapositiva "TALLER EN CLASE" de la presentacion
del curso: descargar VirtualBox, instalar extensiones, instalar tres imagenes
predefinidas (Linux, FreeBSD, Solaris), exportar en OVA, borrar la maquina y
recuperarla desde el OVA.

### Oracle Solaris 11.4
- Fuente oficial: oracle.com/solaris (Plantillas de Oracle VM > plantilla
  VirtualBox x86, 3.3GB)
- Requiere cuenta Oracle (login manual del usuario, no automatizable)
- El usuario inicio sesion en su navegador y completo la descarga de
  `sol-11_4-vbox.ova`
- Importada en VirtualBox como VM **Oracle-Solaris-11.4**
  (4096MB RAM, 1 CPU, disco 33.5GB, tipo Solaris11_64)

### FreeBSD 15.1-RELEASE
- Fuente oficial: download.freebsd.org/ftp/releases/VM-IMAGES/15.1-RELEASE/amd64/
- Imagen VMDK (634MB comprimido en xz) descargada y descomprimida (2.6GB)
- VM creada en VirtualBox: **FreeBSD-15.1** (2048MB RAM, 2 CPUs, controlador
  SATA, tipo FreeBSD_64)
- Incidente: la carpeta `Downloads\SO-VM-Images\` desaparecio inesperadamente
  del sistema de archivos, incluyendo el .vmdk adjunto a esta VM (quedo con el
  disco roto) y el ISO de Ubuntu que ya habia terminado de descargar. Pendiente
  de investigar la causa y volver a descargar/reconstruir.

### Ubuntu 26.04 Desktop (para la imagen "Linux" del taller)
- Fuente oficial: releases.ubuntu.com/26.04 (ISO Desktop amd64, ~6.07GB)
- Se eligio sobre la alternativa de la diapositiva (osboxes.org/opensuse via
  SourceForge) por ser fuente oficial verificable
- Descarga completada una vez, pero el archivo se perdio junto con la carpeta
  SO-VM-Images (ver incidente arriba); pendiente de re-descargar y crear la VM

## Contenido del curso (extraido de la presentacion del docente)

Unidades teoricas: introduccion a SO, clasificacion (anillos concentricos,
maquina virtual, arquitectura UNIX/Android), procesos, comunicaciones, manejo
de memoria (paginacion, segmentacion), E/S, sistema de archivos, gestion de
archivos y usuarios, kernel, seguridad.

Unidades practicas (12 en total durante el semestre): instalacion de SO UNIX
en VMs, editor vi y shell, gestion de procesos/memoria, kernel (compilacion en
clase de FreeBSD), permisologia, gestion de usuarios y archivos, servicios de
red, aseguramiento/seguridad.

Evaluacion: 3 notas (talleres/quices + parciales) mas proyecto final con
sustentacion. Requiere USB o SD de 64GB. Entregas tardias o fuera de formato
bajan al 85% del valor.
