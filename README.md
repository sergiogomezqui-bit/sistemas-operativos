# Sistemas Operativos (UAO)

Trabajo del curso Sistemas Operativos, Universidad Autónoma de Occidente (docente: Mario Wilson Castro).

## Contenido

- **Taller de comandos Unix (Unidad de Aprendizaje #3)** — comparación de comandos entre Linux, Oracle Solaris 11.4 y FreeBSD 15.1, verificados en vivo en máquinas virtuales reales (no solo documentación):
  - [`ComandosUnixAGOSTO25_2026.xlsx`](ComandosUnixAGOSTO25_2026.xlsx) — tabla de 91 comandos completada (columnas Linux/Solaris/FreeBSD)
  - [`Talleragosto252026.docx`](Talleragosto252026.docx) — enunciado original del taller
  - [`session-log/`](session-log/) — taller resuelto con salidas reales de terminal, scripts de verificación usados, capturas de pantalla y una bitácora detallada de cómo se resolvió cada punto (ver [`session-log/README.md`](session-log/README.md))

## Metodología

Cada respuesta se probó de verdad en la terminal (Linux vía WSL2, Solaris y FreeBSD vía VirtualBox), no se copiaron respuestas de documentación sin verificar. El detalle completo, incluyendo correcciones que surgieron al verificar en vivo, está en [`session-log/README.md`](session-log/README.md).
